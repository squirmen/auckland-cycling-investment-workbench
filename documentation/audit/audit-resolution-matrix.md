# Release audit and resolution matrix

Status meanings: **closed** has verifiable repository evidence; **release
gate** must be closed before a public tag; **ongoing** is repeated for every
data release. This matrix does not replace the automated checks or signed data
licence review.

| Area | Risk identified | Resolution / evidence required | Status |
| --- | --- | --- | --- |
| Repository boundary | Earlier experimental work mixed application code, raw data, generated maps, and unrelated research | Standalone repository rooted at `auckland-cycling-investment-workbench`; only source, tests, configuration, schemas, documentation, and lightweight examples are eligible for tracking | closed |
| Implementation provenance | Published PCT methods could be confused with reuse of PCT application code | The independently structured implementation, comparison scope, licence boundary, and mandatory re-review conditions are documented in [`pct-provenance-review.md`](pct-provenance-review.md). Shared material is limited to cited mathematical terms, scenario identifiers, and numerical coefficients. Retain the official PCT application's AGPL-3.0 and the `pct` package's GPL-3 notices; repeat the public-tree provenance and similarity scan before each tag | closed for the reviewed source state; recurring pre-tag gate; no legal conclusion made |
| Software licence | Package metadata and root licence could conflict | MIT text in `LICENSE`; MIT identifier in package metadata and `CITATION.cff` | closed |
| Third-party rights | A software licence could be read as covering data, maps, or articles | Separate `DATA_LICENSES.md`, notices, open/restricted reference split, and machine-readable decisions for all 18 configured sources plus every proposed public layer, basemap, and screenshot in `public-layer-rights.csv` | closed for decision framework; release gate for pending sources and exact release asset |
| Fail-closed public export | A permitted-looking derived layer could silently include an unknown or restricted source | Require a configured source and matching rights decision for every layer source ID; include only `redistribution: permitted` sources with an explicit include decision; reject selected layers with missing, conflicting, unknown, or restricted records. An optional unresolved source is acceptable only when no exported layer references it and every dependent control is omitted or disabled | closed in implementation contract; verify tests and exact release payload |
| Secrets and identity | Tokens, credentials, private keys, or personal filesystem paths could enter a public repository | Ignore common credential files; configuration accepts external paths/secrets; scan tracked text and history before tag; use no personal absolute paths in public files | release gate |
| Restricted references | Paywalled or licence-unclear PDFs could be committed | Track citation/acquisition metadata only in `references/restricted`; ignore all other contents of that directory | closed |
| Generated and raw data | Large, mutable, or non-redistributable files could overwhelm or contaminate Git history | Ignore raw/interim/processed/run/export directories; fetch through a checksummed registry; publish only permitted release artifacts | closed; ongoing per release |
| Large files | Bundled web data or media could exceed host limits and make review difficult | Keep datasets external; size-check every tracked file; retain seven lossless screenshot masters, optimised WebP copies/thumbnails, and only the verified open PDFs | release gate |
| Dependency reproducibility | Unpinned direct or transitive dependencies can change results | Pin supported runtime and dependencies; commit Python and web lockfiles; run a clean install in CI | release gate |
| Container dependency licences | Publishing a container could omit notices or source obligations for redistributed executables | Record `osmium-tool` 1.15.0 (GPL-3.0) and GDAL 3.6.2 (MIT/X-style) in `NOTICE.md`; preserve Debian package copyright files; verify the exact image inventory and provide GPL corresponding source through a compliant release mechanism | release gate before any public container image |
| Automated quality | A map can look plausible while equations, units, topology, or schema are wrong | Unit, property, integration, schema, lint, type/build, and browser smoke tests in CI; enforce coverage threshold without treating coverage as correctness | release gate |
| Configuration validity | Unknown keys or implicit defaults make runs irreproducible | Strict versioned configuration and JSON Schemas; reject unknown keys and incompatible units | release gate |
| Build provenance | Outputs could be detached from inputs or source revision, and a cache initially reused artifacts after implementation changes | Run-manifest schema 2 records a deterministic Python source-tree checksum; versioned stage fingerprints separately bind each stage's declared parameter/source scope, dependency hashes, options, and semantic stage version; cache restoration re-hashes artifacts and is explicit in the manifest; emit the final manifest with source/config/lock/output checksums, code revision, stage counts, seeds, warnings, and timestamps | cache invalidation closed and regression-tested; every semantic handler change must increment its stage version; final release-manifest gate |
| Web provenance | A deployed interface could use stale or incompatible data | Validate exported JSON against its schema; embed release ID; make UI and data release agree; screenshot the exact exported artifact. The curated packager now fails closed on unreviewed appraisal and re-hashes transformed payloads | closed for the local asset; repeat at release attachment and Pages preview |
| Policy target | Prototype language treated an 8% commute-cycling share as if it were the adopted TERP target | Describe 8% only as a configurable modelling sensitivity; cite TERP's 17% all-trip cycling-plus-micromobility and 13% distance targets; state denominator mismatch | closed |
| PCT citation | An incorrect journal/DOI and a non-existent route-choice citation appeared in exploratory notes | Use Lovelace et al. 2017, *Journal of Transport and Land Use*, DOI 10.5198/jtlu.2016.862; remove the unsupported Saxe–Miller item; verify all DOI metadata | closed |
| Network-design citation | Liu, Szeto and Long was assigned the wrong year/volume | Correct to 2019, *Transportation Research Part E* 127, 284–307, DOI 10.1016/j.tre.2019.05.010 | closed |
| Demand confidentiality | Numeric zeros and explicit suppression markers were conflated, and suppressed eligible totals could be treated as fixed caps | Preserve total-stated and bicycle release states; use Stats NZ's maximum fixed-random-rounding error of two for numeric releases (numeric zero is 0–2) and 0–5 only for an explicit below-six suppression marker; select or draw joint pairs satisfying bicycle ≤ total stated. The real preparation audit retained 28,168 bicycle-suppressed and 5,453 eligible-total-suppressed Auckland-origin cells | closed in method and full-scale importer evidence; release gate for complete joint-draw and downstream propagation tests |
| Structurally censored OD rows | An OD pair absent from the source could be materialised as observed zero or an invented destination | Retain Datafinder table 121988 version 410594 metadata: rows with total population below six are removed and only people with workplace address available at SA2 are included. Distinguish absent rows from explicit `-999` and numeric zero; carry unlocated-workplace and missing-row mass as unresolved coverage, never fabricated OD demand | closed in method; release gate for source-coverage ledger and omission fixtures |
| Demand universe and margins | The full-origin SA2 margin could be used as a hard control for a differently scoped internal-Auckland OD table | Treat origin and destination margins as bounded, soft evidence unless exact geography, direction, category, exclusion, and confidentiality universes reconcile. Record the audited 874,065 full-origin margin versus approximately 610,101 published internal OD trips plus suppression; retain outbound, unresolved-scope, unsnapped, and unreachable demand in ledgers and coverage denominators | release gate: demonstrate source-universe reconciliation or retain soft-only use and publish ledger/coverage evidence |
| Behavioural response | A discontinuous or fixed-share response would create unsupported precision | Use continuous bounded odds-elasticity response; expose elasticity and validate/sensitivity-test it | closed in method; verify implementation |
| Connectivity claim | A top-OD low-stress share was liable to be confused with a transferable citywide index | Name a completed calculation the CIW OD low-stress connectivity share; state denominator and weights; report coverage and unreachable pairs; avoid cross-city comparison without harmonised method/data; withhold the Auckland point estimate until full-network rerouting executes | definition closed; Auckland production result withheld |
| Portfolio optimality | A single ordered rank could overstate optimality and double-count static effects | Provide named transparent presets and a multi-objective Pareto frontier; recompute cumulative treatments over the whole affected market; claim no global optimum; identify the current retained-path choice-set limit rather than calling it full-network rerouting | presentation and retained-path recomputation closed; full-network production rerouting remains open |
| Economics | A simplified annuity could be mistaken for a business-case BCR | Implement lifecycle cash flows in common real prices, demand ramp, O&M, renewals, residual, and applicable MBCM parameters; label output indicative. Public packaging exposes appraisal only when the capability is reviewed; the current asset nulls BCR fields and disables Appraisal | method closed; public research asset fail-closed; decision-use inputs pending |
| MBCM currency | Earlier values predated the current manual and discount rules | Use MBCM v1.7.5 for calculations commencing on or after 29 May 2026; cite General Circular 26/01 for the version update and the separate General Circular 25/01 for stepped non-commercial discounting and the required 8% sensitivity; record applicable worksheets | closed in method; verify implementation and release inputs |
| Counter validation | Future scenario flows, wide spatial matching, and a median ratio could be mistaken for predictive validation | Validate a comparable present-day quantity; strict match/direction/period rules; report coverage, bias, MAE, RMSE, correlation, calibration, residuals, and spatial holdout | release gate |
| Uncertainty | A narrow conditional interval could be read as total predictive uncertainty | Use seeded Latin-hypercube parameter/scenario analysis plus structural/spatial scenarios and rank stability; publish bounds and distributions | closed in method; verify outputs |
| Auckland source rights | Public access was liable to be mistaken for redistribution permission | Primary-source review permits exact Stats NZ journey-to-work table 121988, SA1 population, SA2 geography, Auckland boundary, SA2 margin, and Business Demography; the Ministry school directory with unused personal fields excluded; Geofabrik OSM under ODbL; AT Cycle Facility Network; and LINZ layer 51768. OpenFreeMap is permitted for attributed live contextual display without caching; CARTO remains excluded. NZDep is now an optional separate source and remains pending, as do Future Connect, the RLTP snapshot, configured counter files, CAS export, and archived GTFS-derived nodes | release gate: resolve pending inputs or omit their dependent public layers and controls |
| Terrain evidence | A licensed elevation input could still be methodologically unsuitable | Exact LINZ layer 51768, attribution, VRT hash, and all 32 referenced tile byte counts/hashes are now recorded in a self-hashed schema-1 manifest. LINZ's statement that the contour-interpolated 8 m DEM is unsuitable for terrain analysis still requires replacement or defensible validation | integrity closed; methodological release gate |
| Accessibility and screenshots | Attractive images can omit units, attribution, scenario, or uncertainty | Capture all seven specified states as 1800×1100 lossless masters with run ID, status, legend, required on-map attribution, adjacent data credits, alt text, WebP copies, thumbnails, metadata, and checksums; use the tile-free Analysis mode for deterministic captures and keep CARTO disabled | closed after the 31 August interface recapture; repeat after any later UI or data change |
| Documentation integrity | Numeric findings can drift from rebuilt output | Keep result values out of narrative until generated from the tagged manifest; verify links, LaTeX, CFF, BibTeX, and CSV in CI | release gate |
| Development artifacts | Non-product notes, temporary review text, or local instructions could leak into release files | Scan tracked files for private paths, temporary markers, editor artifacts, and non-product development chatter; retain required scholarly and software attribution | release gate |
| Publication claims | A reproducible screening model could be overstated as causal, predictive, optimal, or appraisal-compliant | Use the claim language in `white-paper/claims-evidence-matrix.md`; label all current outputs synthetic; require real-data release evidence for every Auckland claim | closed; ongoing review |

## Final pre-tag evidence packet

- Clean checkout, dependency install, tests, lint, package build, and web build.
- Secret/path/large-file/licence scan over the complete Git history.
- One end-to-end demonstration run with manifest and checksums.
- External validation report with all eligible and excluded counter sites.
- Sensitivity summary and rank-stability table.
- Data and PDF licence sign-off.
- Seven required screenshots generated from the exact proposed artifact, with
  masters, WebP copies, thumbnails, metadata, and checksums.
- Citation, link, schema, CFF, BibTeX, CSV, and LaTeX validation.

The current state of these gates and the evidence needed to close them are in
[`release-readiness.md`](release-readiness.md).
