# Run-manifest evidence

The versioned contract is
[`schemas/run-manifest.schema.json`](../../schemas/run-manifest.schema.json).
Local synthetic demonstration runs may be used during development, and the
`runs/` directory is deliberately excluded from public source control. A
complete local Auckland raw-to-web research snapshot has now succeeded; its
evidence, predecessors, and remaining blockers are recorded in
[`auckland-real-stage-evidence.md`](auckland-real-stage-evidence.md). It is not
yet the manifest of an approved public tag.

A releasable Auckland manifest must be generated by the exact proposed tag and
must include, at minimum:

- release/run identifier, configuration and schema versions, and code revision;
- locked Python, Java, R5, GDAL, osmium, Node.js, and frontend versions;
- random seeds, implementation-source checksum, and stage fingerprints;
- every source URL, title/version/vintage, byte count, SHA-256 hash, licence,
  rights decision, and attribution;
- output file hashes and schema versions;
- row counts, demand totals by source state, structural omissions, routing
  failures, snap-distance diagnostics, component coverage, and timings;
- validation, appraisal, uncertainty, frontier-stability, and manual-audit
  references; and
- the exact checksummed web-layer manifest and screenshot run identifier.
