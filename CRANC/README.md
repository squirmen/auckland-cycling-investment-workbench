# Local CRANC review inputs

The collaborator-supplied backend and frontend ZIPs in this directory are
deliberately ignored by Git. They are retained locally, not redistributed as
SPAN source or bundled in a website release. Their review fingerprints are in
[`cranc-source-review.json`](../documentation/research/cranc-source-review.json).

The integration entry points and remaining work are documented in
[`cranc-integration.md`](../documentation/research/cranc-integration.md#where-to-connect-cranc).
The existing browser exchange does not execute CRANC or transmit origin data.
